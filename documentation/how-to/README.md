# How-to — secure-space (umbrella)

Task recipes that span more than one project, or that concern the workspace as a whole.

## When to write here (umbrella scope)

- Add a new project to the umbrella
- Rotate secrets that multiple projects consume
- Run integration flows spanning projects

## When to write in a project instead

- Anything scoped to one project → `<project>/documentation/how-to/`
