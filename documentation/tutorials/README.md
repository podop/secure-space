# Tutorials — secure-space (umbrella)

Cross-project learning-oriented walkthroughs live here. Project-specific tutorials go under `<project>/documentation/tutorials/`.

## When to write here (umbrella scope)

- End-to-end onboarding that spans more than one project
- "Set up the whole workspace" walkthroughs

## When to write in a project instead

- Any tutorial that only touches one project → `<project>/documentation/tutorials/`

See [`skills/diataxis-docs`](https://github.com/PavelValentov/datarim) for the taxonomy.
